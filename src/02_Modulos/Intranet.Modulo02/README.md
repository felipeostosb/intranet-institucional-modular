¡Bienvenidos Equipo 02! Este es su proyecto independiente dentro de la Intranet Institucional.

## 🚀 Reglas de Trabajo para su Equipo:
1. **Su Carpeta Exclusiva:** Todo el código de su equipo (Controladores, Vistas Razor, Modelos, SQL) debe estar dentro de `src/02_Modulos/Intranet.Modulo02/`.
2. **Su Ruta Web:** Su módulo se accede en el navegador en la ruta: `/Modulo02`.
3. **Su Base de Datos:** Tienen asignado el esquema soberano `mod02` en PostgreSQL 16 (Servidor `postgres` en `db_intranet_iestp` / Adminer puerto 8080).
4. **Git Branch:** Creen sus ramas de trabajo como `modulo02/nombre-de-tarea` (usa la opción 2 del asistente `./dev.sh` o `.\dev.ps1`).
