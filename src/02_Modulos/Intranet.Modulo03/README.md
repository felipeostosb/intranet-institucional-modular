## 🚀 Reglas de Trabajo para su Equipo:
1. **Su Carpeta Exclusiva:** Todo el código de su equipo (Controladores, Vistas Razor, Modelos, SQL) debe estar dentro de `src/02_Modulos/Intranet.Modulo03/`.

4. **Git Branch:** Creen sus ramas de trabajo como `modulo03/nombre-de-tarea` (usa la opción 2 del asistente `./dev.sh` o `.\dev.ps1`).
